# L4D2MutiMod

Release builds of Left 4 Dead 2 server-side SourceMod extensions and plugins by **Crimson**.

**This repository ships binaries only — no source.** Every artifact is distributed
as a GitHub [Release](https://github.com/Crimson-DawnLight/L4D2MutiMod/releases). What you
browse here is documentation: what a thing does, and where its files go, before
you download anything.

## Contents

| | Directory | What goes there |
|---|---|---|
| Extensions | [`extensions/`](extensions/) | SourceMod C++ extensions |
| Plugins | [`plugins/`](plugins/) | SourcePawn plugins |

## Releases

| Item | Kind | Version | What it does | Download |
|---|---|---|---|---|
| [sendproxy](extensions/sendproxy/) | extension | 3.4.1 | Overrides one entity property for one client, at packet time | [latest](https://github.com/Crimson-DawnLight/L4D2MutiMod/releases/latest) |

## Install

Each item's own `README.md` states exactly which file goes to which path. Release
archives mirror the server directory tree, so extracting one into your server root
puts everything where it belongs.
